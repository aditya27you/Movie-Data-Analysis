# Data-Analysis

# 🎬 Netflix Movie Data Analysis

This project analyzes Netflix movie data using **Python**, **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**.

# Overview
The script cleans and preprocesses the dataset, converts release dates to years, categorizes movie ratings, and visualizes important trends.  
It helps identify:
- Most frequent movie genres  
- Popularity and rating distributions  
- Movies with highest and lowest popularity  
- Year with the most Netflix movie releases  

# Requirements
Make sure the following libraries are installed before running the script:
```bash
pip install pandas numpy matplotlib seaborn
```

# How to Use
1. Upload your `moviedta2025.csv` file when prompted.  
2. Run the script (`netflixmovie.py`) in **Google Colab** or any Python environment.  
3. The data will be cleaned, categorized, and visualized automatically.  
4. View the generated plots and printed summaries for key insights.  

# Insights
The analysis reveals patterns such as:
- **Most common genre:** Drama  
- **Highest popularity:** *The Gorge* (2025)  
- **Lowest popularity:** *Sympathy for Delicious* (2010)  
- **Top year for releases:** 2025
